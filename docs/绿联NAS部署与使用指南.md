# 人生簿（Lifebook）`v0.1.0` 绿联 NAS 部署与使用指南

> 面向绿联 `DXP4800 Plus`（`UGOS Pro`）家庭服务器容器自托管部署（基于 `v0.1.0` 正式版本），默认服务端口为 **`3220`**（避开同类项目「时间簿」使用的 `3210` 端口），数据全部持久化在宿主目录 `/volume1/docker/lifebook/data`。

---

## 一、容器部署步骤（Docker Compose）

1. **准备宿主机目录**
   在绿联 NAS 文件管理或 SSH 终端中创建持久化数据目录：
   ```bash
   mkdir -p /volume1/docker/lifebook/data
   ```

2. **获取项目源码并配置环境变量**
   在 NAS 上克隆开源仓库到 `/volume1/docker/lifebook/app`（或直接上传对应发行版源码包并解压进入目录），然后复制示例环境变量文件：
   ```bash
   git clone https://github.com/kkuxb/lifebook.git /volume1/docker/lifebook/app
   cd /volume1/docker/lifebook/app
   cp .env.example .env
   ```
   按需编辑 `.env`（也可留空 `APP_PASSWORD`，首次打开网页时在界面上设置口令）：
   - `PORT=3220`
   - `DATA_DIR=/data`
   - `TZ=Asia/Shanghai`
   - `APP_PASSWORD=你的私人访问口令`

3. **构建并启动容器**
   ```bash
   docker compose up -d --build
   ```
   等待十余秒后验证健康检查接口：
   ```bash
   curl http://127.0.0.1:3220/api/health
   ```
   返回 `{"ok":true,"status":"healthy",...}` 即表示启动成功。

## 二、首次访问与日常使用

1. **电脑与手机全屏访问（PWA）**
   - 电脑浏览器访问 `http://<你的NAS地址>:3220`。
   - 手机浏览器打开同一地址后，选择「添加到主屏幕」，即可作为全屏独立应用使用。
   - 右上角支持一键切换「浅色护眼暖白纸面」与「夜间深色模式」。

2. **历史日记搬家（原平台 ZIP 压缩包导入）**
   - 点击右上角「⚙ 设置」→「历史搬家」→ 上传原平台导出的标准 `ZIP` 压缩包。
   - 预览页会自动过滤空白占位草稿、剥离标题重复日期前缀、展示「旧 12 项 → 新 8 档心情」归并映射，并列出同日冲突清单（默认跳过并保留已有，也可按条切换为覆盖或合并追加）。
   - 如对某次导入结果不满意，可在下方「历史导入批次」一键无损撤销。

3. **断网防丢与当日 5 份快照**
   - 写作过程会自动在浏览器本地缓存草稿，断网时顶部同步胶囊变为橙色「离线暂存中」，恢复联网后自动补写同步。
   - 服务端每次保存会自动保留当天（`Asia/Shanghai` 自然日）最近 `5` 份防丢快照，跨入下一自然日后自动清理早于当日的临时快照，防止数据库膨胀。

## 三、大模型接入与「时间簿」只读联动

1. **模型服务配置（可选）**
   - 在「⚙ 设置」→「✦ 模型与联动」中选择接口协议（`OpenAI 兼容` / `Gemini 原生` / `Anthropic 原生`），填写接口地址、密钥与模型标识。
   - 密钥由服务端使用 `AES-256-GCM` 加密保存，绝不回传前端明文。
   - 点击「⚡ 检测连通性」验证通过后即可启用：
     - 保存日记时静默生成单篇结构化日概要（日历格支持点击「✦ 补算概要」，设置内支持暂停与断点续跑批量补齐）；
     - 首页「✦ 问问过去的自己」支持基于 4 个只读工具进行回忆问答（硬限最多 4 轮调用，附带可点击日期原文出处）；
     - 统计页支持按自然月（次月 1 日解锁）/自然年（次年 1 月 1 日解锁）生成深度月报、深度年报与双高光时间轴。
   - 若关闭或模型离线，写日记、检索、热力图与基础统计仍 100% 正常工作。

2. **「时间簿」局域网只读联动（可选）**
   - 在「✦ 模型与联动」下方填写同一局域网下的「时间簿」访问地址（如 `http://<NAS地址>:3210`）与访问口令，点击测试连通。
   - 全程通过时间簿公开只读接口拉取汇总，**零改动时间簿源码或数据文件**；离线时自动平滑降级为纯日记深度复盘。

## 四、每日热备、导出与数据恢复

- **每日自动热备**：服务端每 24 小时自动执行一次 `SQLite` 在线热备，保存在 `/volume1/docker/lifebook/data/backups/`（最多保留最近 14 份）。
- **手动备份与导出**：在「⚙ 设置」→「备份与回收站」可随时点击「🛡 立即执行热备」、下载单份 `.sqlite` 备份，或导出全量 `JSON` 与标准 `Markdown + 图片` 压缩包。
- **还原方法**：停止容器后，将选定的热备 `.sqlite` 文件覆盖为 `/volume1/docker/lifebook/data/lifebook.sqlite` 并重启容器即可完成恢复。
