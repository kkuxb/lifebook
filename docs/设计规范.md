# 人生簿 · 视觉与动效设计规范（草案）

> 与「时间簿」保持同一家族的干净、平面、克制质感，同时针对**夜间长时间撰写长文与翻阅回忆**，引入「护眼暖白写作纸面」与「深色夜间模式」双套语义化主题变量。正式开发时所有色值均通过样式变量管理，不在组件内散落写死。

---

## 1. 设计原则

- **平面、克制、护眼**：工作台区域保持纯净浅灰/深石板底色与明确卡片边界；正文写作纸面采用更柔和的暖白/深炭纸底，降低长时间凝视屏幕的眩光与对比度疲劳。
- **语义唯一、色彩克制**：暖黄只留给「最核心操作」与记忆点缀（写今天日记、荧光高亮命中词、今日标记、模型智能摘要 `✦` 徽标强调）；情感表达由 8 档高区分度心情表情与 10 套柔和标签色承担，不抢占正文注意力。
- **手感一致**：所有可点击的日记卡片、日历格与按钮均保留轻柔上浮与微按回弹；系统开启「减少动态效果」时自动关闭全部动画。

### 3.3 热力图冷暖高反差色阶（浅色 / 深色）

- **按字数着色（冷暖跨度 5 档，拉大简记与厚重长文的视觉差距）**：
  - 未记录：`#EBEEF5`（浅） / `#202532`（深）
  - 1 ～ 400 字（简短轻记 · 淡冰蓝）：`#CBE4FA`（浅） / `#1E3A5F`（深）
  - 401 ～ 800 字（常规日记 · 晴空蓝）：`#7CC0F5`（浅） / `#2B6CB0`（深）
  - 801 ～ 1,300 字（充实长篇 · 暖金黄）：`#FBBF24`（浅） / `#D99B16`（深）
  - 1,301 字以上（厚重长文 · 琥珀赤橙）：`#EA580C`（浅） / `#F97316`（深）
- **按心情着色**：取当天主心情在「3.2 心情字典」中的情绪代表色。

### 3.4 模型智能标识与问答出处组件

- **智能摘要徽标**：使用柔和暖黄微底胶囊 `✦ 智能概要`（浅底 `#FFF7D1` 字 `#9A5800`；深色底 `rgba(245,200,59,.16)` 字 `#FCD34D`），与正文清楚区分；关闭模型或无摘要时自动降级展示原文字句，无报错红框。
- **回忆问答出处引用胶囊**：回答下方横向排列可点击日期徽章（如 `2026-11-02 · 海边出差`），悬停上浮、点击直达该篇原文。

## 4. 字体与排版层级

- **字体族**：优先使用精致中文无衬线系统堆栈（思源黑体 / 苹方 / 微软雅黑）搭配等宽数字对齐（`tabular-nums`）；代码块使用等宽字体。
- **正文舒适阅读规范**：
  - 居中写作纸面最大宽度：`760px`（内边距桌面 `40px × 48px`，手机 `20px × 24px`）；
  - 正文字号：`16px`，行高 `1.82`，段间距 `12px`，兼顾一两千字长文连贯浏览不疲劳；
  - 标题大号字：`42px / 800`（首页日期），`28px / 800`（日记一句话标题），`20px / 700`（文内二级标题），`17px / 700`（文内三级小节标题，带柔和左侧竖条或下微间距）。

---

## 5. 圆角、阴影与动效

- **圆角体系**：普通卡片与写作纸面 `20px`；抽屉与模态弹窗 `24px`；导航胶囊 `14px`；按钮与输入框 `12px`；标签/心情徽章 `999px`；热力图方格 `4px`。
- **阴影体系**：
  - 浅色：`0 1px 2px rgba(17,24,39,.04), 0 10px 24px -16px rgba(17,24,39,.16)`；
  - 深色：`0 1px 2px rgba(0,0,0,.35), 0 12px 28px -16px rgba(0,0,0,.6)`；
  - 悬停上浮：`translateY(-3px)`，耗时 `0.26s`，曲线 `cubic-bezier(.2,.8,.2,1)`；按钮按下 `scale(.97)`。
