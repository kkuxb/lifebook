### 非阻断建议（供后续版本优化，不阻断本轮收口）

1. **[V2 / 导入解析]** `packages/core/src/import-parser.ts` 中 `stripDatePrefixFromTitle` 在遇到连续写两次的日期前缀（如 `2026-10-05 2026-10-05 秋游`）时因 `break` 只剥离第一段而留存 `2026-10-05 秋游`；建议改为循环剥离直至开头不再匹配日期前缀。
2. **[V2 / 导入预览计数]** ZIP 导入解析将附件同时以全路径和文件名存入同一 `attachments` Map，导致含 1 张本地图片的包在预览界面显示「本地图片 2 张」；建议按真实文件集合或唯一文件数统计显示。
3. **[V1 / 断网保存提示]** 断网状态下点击「立即保存」时底部 Toast 仍显示「已保存至本地防丢队列与服务器」（尽管右上角同步胶囊已准确变为橙色「离线暂存中（1）」），建议在离线分支提示「已暂存至本地防丢队列，联网后自动同步」。
4. **[V1 / 自动同步后编辑器徽标]** 断网恢复并自动完成后台同步后，顶部全局胶囊已转为「数据已同步」，但写作页左上角草稿徽标仍停留在「离线暂存中（联网后自动同步）」直至再次保存或刷新；建议同步成功事件同步刷新编辑器本地状态。
5. **[V1 / 快照时间戳显示]** 「当日防丢快照」弹窗展示的时间字符串为 UTC 时间（如 `02:56:27`），建议格式化为 `Asia/Shanghai` 本地时间展示，与用户心智一致。
