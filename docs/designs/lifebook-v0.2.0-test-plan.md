## 一、测试对象与无打扰隔离规程（`qa` 必读）

1. **只测独立发布包与独立打包桌面成品，绝不直接测开发源码目录**：
   - 使用 `fde-qa` 技能自带解压校验器核验 `dev` 交付的 `lifebook.zip`（路径见面板交接消息 `workspace-data/outputs/lifebook/v0.2.0-R<轮次>/lifebook.zip`）：
     ```powershell
     python "<fde-qa技能目录>/scripts/unpack_verify.py" --zip "<package_path>" --dest "<项目根目录>/workspace-data/tmp/qa/v0.2.0-R<轮次>/pkg"
     ```
   - 另核对 `dev` 交付的独立桌面产物目录 `workspace-data/outputs/lifebook/v0.2.0-R<轮次>/desktop/`：确认同时存在体积合理的 Windows NSIS 安装程序（`*-setup.exe`）与便携可执行程序（`*.exe`）。
2. **包内静态安全与纯净必查项（父级 `qa` 先做）**：
   - 确认发布包内无 `apps/desktop/src-tauri/target/` 编译缓存、无 `.env`（仅允许 `.env.example`）、无 `*.sqlite*`、无真实口令/密钥、无开发机用户/工程绝对路径、无硬编码局域网真实 IP（`192.168.*` 等）。
3. **一次性环境准备与全仓确定性回归（准备时间单列）**：
   - 在 `<pkg_dir>` 内执行：
     1. `corepack pnpm install`
     2. `corepack pnpm typecheck`
     3. `corepack pnpm test`（确认原有全部测试及新增时间簿结构/问答测试 `100%` 通过）
     4. `corepack pnpm build`
4. **完全隔离盲测规范**：
   - 为 `V8`～`V11` 各启动隔离端口（`15301`～`15399`）与临时数据目录 `workspace-data/tmp/qa/v0.2.0-R<轮次>/cases/<编号>/`。
   - 桌面端实测 **必须设置环境变量 `LIFEBOOK_DESKTOP_CONFIG_DIR`** 指向当前用例的隔离临时目录（例如 `workspace-data/tmp/qa/v0.2.0-R<轮次>/cases/V10/desktop-cfg`），绝不写入系统真实用户配置目录！
   - 测完后必须按自有 `PID` 精准停止临时后端、模拟 HTTP 服务与桌面端进程，并确认无桌面进程残留；桌面引导页截图须由 `qa` 使用 `read_file` 亲眼核对视觉一致性与中文显示无乱码。

## 三、预算与授权边界

- **预算上限**：每场景独立子智能体盲测时长 `<= 420` 秒（硬上限 `900` 秒）；研发–测试返修最多 **`3` 轮**；真实计量通过 `metrics.py` 采集入库（禁止估算 Token）。
- **允许边界**：在 `workspace-data/tmp/qa/v0.2.0-R<轮次>/` 下解压、装包构建、起隔离端口（`15300+`）与运行桌面端实机测试；向 `docs/deliveries/lifebook-v0.2.0-R<轮次>-test-report.md` 写入七维评审报告与 `workspace-data/qa/v0.2.0-R<轮次>/metrics.json` 写入计量。
- **严禁边界**：严禁修改项目源码或被测包；严禁连接绿联生产服务器、真实时间簿或公网模型地址；严禁写入本机真实用户桌面配置目录；严禁不按 `PID` 过滤强杀系统正常进程。
