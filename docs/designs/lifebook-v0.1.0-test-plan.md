## 一、测试对象与无打扰隔离规程（`qa` 必读）

1. **只测独立发布包，绝不测开发源码目录**：
   - 被测包路径以 `dev` 在面板交接元数据中给出的 `package_path` 为准（`workspace-data/outputs/lifebook/v0.1.0-R<轮次>/lifebook.zip`）。
   - 父级 `qa` 首先运行 `fde-qa` 技能自带的解压校验器：
     ```powershell
     python "<fde-qa技能目录>/scripts/unpack_verify.py" --zip "<package_path>" --dest "<项目根目录>/workspace-data/tmp/qa/v0.1.0-R<轮次>/pkg"
     ```
   - 校验失败直接 `@dev [changes_requested]` 打回“包不完整”。
2. **包内静态安全与纯净必查项（父级 `qa` 先做）**：
   - 确认包内无 `.env`（仅允许 `.env.example`）、无 `*.sqlite*`、无真实口令/密钥、无开发机用户/工程绝对路径、无硬编码局域网真实 IP、无测试专用默认后门或测试口径语句、且源码与界面文案中彻底不存在「年度人物侧写」字样。
3. **一次性环境准备与确定性回归（准备时间单列，不计入单场景业务时长）**：
   - 进入解压后的包目录 `<pkg_dir>` 执行：
     1. `corepack pnpm install`
     2. `corepack pnpm typecheck`
     3. `corepack pnpm test`
     4. `corepack pnpm build`
   - 任一失败即记录原始日志并直接判定相应维度不合格。
4. **完全隔离盲测规范**：
   - `V1`～`V7` 每个场景均由父级 `qa` 调用 `invoke_subagent` 启动干净独立子智能体盲测；只给场景业务目标、`<pkg_dir>`、独立临时数据目录 `workspace-data/tmp/qa/v0.1.0-R<轮次>/cases/<编号>-run1/`、独立空闲高端口（建议 `15201`～`15299`）与允许副作用边界；**严禁向子智能体泄露预期结果或 `dev` 自测详情**。
   - 浏览器端验证使用无头浏览器或独立隔离调试实例，**严禁抢占桌面焦点、严禁误杀本机正常进程、测完必须按自身进程 `PID` 精准停止临时服务与模拟服务器**。
   - 关键视觉截图须由 `qa` 使用 `read_file` 亲眼核对是否符合 [视觉与动效设计规范](../设计规范.md)。

## 三、预算与计量口径

| 指标 | 目标值 | 硬上限 | 计量口径 |
| --- | --- | --- | --- |
| **全文检索服务端响应（1,250 篇）** | `< 50 ms` | `100 ms` | `GET /api/entries?q=...` 实测响应耗时 |
| **回忆问答工具调用轮次** | `1～3 轮` | **`4 轮`** | 单次 `/api/ai/qa` 工具循环次数硬限 |
| **单篇日概要 / 月报 / 年报体量** | 符合 `C-17` 深度范围 | 月输出 `<= 3,000` 词元 / 年输出 `<= 5,000` 词元 | 验证提示词传参上限与实际展开段落密度 |
| **单验收场景盲测时长** | `<= 420 秒` | `900 秒` | 各子智能体 `transcript.jsonl` 首尾真实秒数（不含父级 `qa` 一次性 `pnpm install/build` 准备时间） |
| **子智能体消耗计量** | 如实采集 | 如实记录 | 用 `metrics.py` 从子智能体日志提取真实时长、步数与原生 `Token`（拿不到标 `null` 不可用，严禁估算） |
| **研发–测试返修轮次** | `1～2 轮` | **最多 `3 轮`** | 超轮次或需改合同立即 `@coordinator [blocked]` 上报 `PM` |

## 四、授权边界与通过规则

- **允许**：在 `workspace-data/tmp/qa/v0.1.0-R<轮次>/` 下解压安装构建、起本地临时端口（`15200+`）和模拟本地 `HTTP` 服务进行完全隔离测试；向 `docs/deliveries/lifebook-v0.1.0-R<轮次>-test-report.md` 写入七维报告及 `workspace-data/qa/v0.1.0-R<轮次>/metrics.json` 写入计量。
- **严禁**：修改被测包或项目源码；连接真实绿联 NAS 或真实「时间簿」生产端口；向真实公网大模型地址发起付费请求；访问当前项目根目录以外的其他目录；执行不按 `PID` 过滤的全局强杀命令。
- **通过规则**：包内静态安全检查清白 + `typecheck`/`test`/`build` 100% 通过 + `V1`～`V7` 全部满足判据 + 关键界面截图经 `qa` 亲眼核验无视觉破版或「年度人物侧写」残留 + 无“必须修复”级缺陷且全部临时进程已清理，方可向 `@coordinator [done]` 提交收口。
