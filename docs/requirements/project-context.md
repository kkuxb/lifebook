# 人生簿 项目背景

长期业务目标：面向个人的私密、轻快、高颜值每日日记与人生回顾工具，支持绿联家庭服务器容器自托管、电脑与手机网页全屏同步、块级斜杠排版写作、历史日记无损迁移与未来轻量桌面客户端。

当前阶段与下一步见 [文档索引](../README.md)，本页维护背景、范围和事实依据。

## 已确认事实与来源

- 彻底精简原空间里的「灵感小记」模块，聚焦每日日记、回顾、全文检索与统计分析。
- 分两期推进：一期交付绿联家庭服务器容器版与电脑/手机网页版（含 1,244 篇历史数据无损搬家）；二期再打包轻量桌面客户端。
- 编辑器支持完整常用斜杠命令块（标题、列表、待办、引用、分割线、代码块）、划词加粗高亮、粘贴上传本地图片以及自定义日记默认分段模板。
- 历史搬家采用内置「原平台导出压缩包一键导入」向导（本地解析、预览核对、按批次撤销）。
- 界面采用四栏主导航（首页、日历、历史、统计）加右上角同步状态与设置收纳，内置浅色与深色夜间护眼模式，开发前先提供高保真可交互原型确认手感再冻结设计。
- 中文名为「人生簿」，延续「时间簿」干净克制的平面卡片风格，写作区微调为护眼暖白纸面；日期独立存储，标题只填一句话摘要（历史导入自动剥离重复日期前缀）；日常默认一天一篇，另支持不绑单日的专项复盘（如年度复盘）；采用沉浸式居中写作页，右侧按需展开「那年今日」对照侧栏。

## 本期范围

- 一期：首页总览（今日入口、那年今日、年度热力图、标签快捷墙）、沉浸式居中写作页（斜杠菜单、快捷符号、划词工具栏、本地图片、模板套用、那年今日对照）、月历视图、历史与全文毫秒级检索、统计分析、设置与原平台导出包一键导入、全量备份导出与 30 天回收站、绿联容器部署指南。
- 二期：轻量 Windows 桌面安装包与单机/联机双模式。

## 目标环境

- 绿联 DXP4800 Plus（UGOS Pro，x86_64），容器默认端口 3220（避开时间簿的 3210 端口），配合外网安全直连实现手机全屏应用。

## 约束与权限

- 全程零大模型运行消耗，所有功能均为确定性本地计算与存储。
- 原平台数据仅只读导出迁移，严禁反向写入原平台。
- 长文写作必须具备本地防丢草稿暂存、多端防覆盖冲突保护与历史快照。
- 正式发布与验收前须由独立测试评审基于独立发布包完成隔离盲测。

## 工程假设

- 历史日记导出包为原平台标准导出压缩包，内含数据库索引文件与各篇日记文本。
- 单用户个人口令加密访问模式。

- 一期技术设计方案、验收场景清单、时长与返修预算最终冻结。
